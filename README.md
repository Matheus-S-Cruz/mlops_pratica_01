# Pipeline Modularizado de Classificação de Churn

Projeto desenvolvido para a atividade prática da Unidade Curricular de Engenharia de Dados e MLOps.

O objetivo é construir um pipeline modularizado em Python capaz de processar dados de transações de clientes, gerar informações agregadas, treinar um modelo de classificação e realizar uma previsão de churn para um novo cliente.
